## 引き継ぐ戦闘・操作仕様

- 攻撃周期、AT、クリティカル、テンション消費、射程、命中の条件とスキル効果を、見た目の改善だけを理由に変更しない。刃・槍先・拳の実際の通過へ接触開始／終了の位相を合わせる。狙撃銃のスキル込み100%クリティカルと保存済み射撃バランスも維持する。
- 通常コンボは前段命中で次段へ派生する。前段の実姿勢を次段へ渡す。最後の一撃だけの命中で、成立した一連のコンボと同じ吹き飛ばしを発生させない。
- 途中打撃で攻撃をすぐ中断させる仕様へ戻さない。成立した最終打の怯み・軽い吹き飛ばし、倒れてから完全起床までの無敵、空中では命中可能という既存ルールを保つ。
- 通常歩幅は承認済みの幅を維持し、歩行速度は足の頻度で見せる。攻撃時の方向入力による高速接近と、ダッシュの地上滑走は別の動作として保つ。
- プレイヤーは生存する相手へ常時ロックし、通常攻撃の武器方向はその攻撃の確定方向を基準にする。胴の演出旋回と、相手に対する穂先／刃の運びを混同しない。
- 承認済みのソード通常4段、横薙ぎ一周のチャージ、盾有無の分岐、着地回復、支持足の接地を維持する。

## 品質確認で見るもの

正面・側面・斜めの固定カメラで、準備から回復まで同じ時間を連続表示する。脚・腰・胸・腕・武器を順に隠す編集で中間姿勢の不具合を見えなくしない。

確認するのは、全機体の有限で連続する関節、握りから武器が離れないこと、両手武器の補助手が柄に沿うこと、盾と剣を同じ軌道にしないこと、刃や打撃部が意図する標的を通ること、支持足の世界位置が不要に滑らないこと、装甲・盾・武器の交差、実コンボ境界と溜め解放での姿勢継承。同じ時刻を再描画して関節や足の位置が変化しないことも確認する。

攻撃者のポーズが違うだけで同じ手首の反転を繰り返す形になっていないか、二刀の非攻撃側、拳のガード側、盾、長柄の補助手に明確な役割があるかを評価する。参考映像で見えなかった足接地・荷重・角度については、ゲームで安定する独自値として検証し、原作の測定値とは呼ばない。
