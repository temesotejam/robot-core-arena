# ランスのモーション見直し

確認日：2026年10月4日。ユーザー承認済みのLBX風体型を基準に、ランスの通常3段と満溜めを見直した。

## 提供映像で確認した動き

元の『ダンボール戦機W』MP4から、第14話15:37.4–15:40.9と第19話16:37.0–16:38.8を再抽出した。今回直接確認したのは5fpsの18枚／9枚、計27枚。以前の連続フレーム調査は[MELEE_ANIMATION_REFERENCE.md](MELEE_ANIMATION_REFERENCE.md)に残る。全58話を再び通し視聴したという意味ではない。

- 第14話：紫機の長柄とカイト盾。柄を胴横に残して胸と盾の向きを変え、穂先を相手の丸盾へ運ぶ。盾腕と武器腕の回収が別に見える。
- 第19話：白橙機が柄を肩の外上へ引き、盾を前に残した空中回収から低い再接近へつなぐ。空中移動とカットがあるため、地上の支持足・荷重周期の実測には使わない。

低い突き・高い突き・最終踏み込みの3段配列、地上の足運び、関節角と時間配分はこのゲーム用の独自設計。上記の映像に同じ3連撃があるとは主張しない。

## 実装した動き

`src/lance-motion.js`へ専用の全身動作を分離した。骨盤の逆回旋と沈み込みで武器を引き、骨盤が胸より先に進み、折り畳んだ肘と肩から穂先へ力を伝える。中間の握り位置は速度を保つ連続曲線で結び、各キーで止まる動きを避けた。

|段|引きと突き|回収|
|---|---|---|
|1：低い突き|腰横に引いて膝と腰を沈め、低い線で突く。|肘を先に畳み、盾を残して高い引きへ渡す。|
|2：高い突き|武器を肩の外上へ持ち上げ、相手の上体へ向ける。|槍と盾を別々に回収し、最後の深い引きへ渡す。|
|3：踏み込み|大きい骨盤・胸の回旋、約8度の前傾と深い荷重で押し込む。|握りを回収してから前足を集め、固有の構えへ戻る。|

槍の方向は攻撃開始時の正面を基準に決め、胸の回転を腕全体で補償する。盾は正面を覆いながら独立して動かし、盾なしでは空き腕を後方へ運んで釣り合いを取る。先行入力で次の肩外の引きを準備し、段の間に直立待機を挟まない。満溜め解除は保持した引きをそのまま使い、待機へ戻して再準備しない。

攻撃の長さ、3段の数、テンション消費、威力、射程、前進量、命中・派生条件は従来のまま。接触窓も通常0.34／0.455／0.51、満溜め0.36／0.46／0.51を保持する。腕と脚の骨長、承認済み体型、ソードとナックルの動作は変更しない。

## 検証と再撮影

`npm run check`と199件のテストが成功。追加した4件では、腰から胸への先行、低・高・最終突きの差、実表示の槍と盾の方向、中間の握り速度、肘の回収、溜めと先行入力の引き継ぎを確認する。既存の30／60／120fps・全5フレーム・盾あり／なし・通常／溜めの命中、武器貫通、FK、接地、連撃継承、待機への復帰も通る。ランスについて従来の直立条件（0.04rad未満）を制御した前傾へ更新した。数値接続・接地・貫通の許容値は広げていない。他17武器の描画スナップショットは更新せず保持した。

専用ワークフロー`lance-preview.yml`で全5フレームのランスの実ブラウザ検証と通常／満溜めの映像を生成する。`scripts/melee-preview.cjs --weapon=lance`は有限資源の実Battleへ押下・解除を与え、命中で成立した3段と構え戻しを60Hzで記録する。`--charge`は通常の長押しと解除を使う。相手のLPや資源を途中補充せず、保存したモデルの座標・回転を補間せず再描画する。動画は機体と無地の床、影だけを表示し、側面・斜めを等速と半速で確認できる。固定カメラは全記録の範囲から決め、画面切れ、腕と握りの接続、支持足、WebGLと元ソースの一致を検証する。
