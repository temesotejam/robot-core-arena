## 最初の確認時点（cba31d9）の比較と調整方針

2026年10月3日の全身表現の更新（cba31d9）では、歩行の胸と骨盤の逆回旋、肩と肘からの腕振り、視線の安定、ソードの骨盤先行と反対腕の引き戻しを追加しています。参考映像の確認前に実装した更新であり、これを映像との一致を検証した再現版とは扱いません。

映像では、武器の角度だけでなく、動作の目的に合わせて脚・胸・左右の腕を構え直すことが明瞭です。当時のソードには全身の連動がありますが、映像の飛び込むような接近や、低い受け止め姿勢に比べ、前傾と姿勢の高低差が小さく見えます。

この確認後の`ddbcfee`では「低くためる→鋭く踏み込む／振る→身体で動きを受け止める→次の構え」の段別姿勢と支持足を調整しました。現在も残る時間配分・盾配置・着地回復の検討点は詳細記録にあります。映像には跳躍・空中斬撃もありますが、それを全通常攻撃へ加えることは確定仕様ではありません。

第2話の詳細確認では13:25.471以後の高い刃の準備と、13:25.772以後の最初の明確な火花を区別しました。接触直前の速い数コマだけを準備全体の長さとして扱いません。また、13:26.439以後の盾の火花は別の味方機の接触で、青い二刀機の斬撃と混ぜません。ソード初段の標的を掃く区間は標準で約0.081秒ですが、動画の火花が見える時間や一振り全体とは異なる定義です。

普通の歩行について、安定した一周期全体を測れる場面はこの確認範囲では得られていません。アニメの戦闘時の跳躍や飛び込みを普通の歩行へ直接置き換えず、ユーザー指定で戻した歩幅と現在の速度を基準にします。支持足の世界位置・向き、剣の握り・切断面・命中時刻、コンボと資源の戦闘ルールを検証の基準に残します。

元映像には同じ姿勢を複数コマ保持する箇所もあります。参考にするのは強い姿勢の差、準備・加速・余韻の配分です。同一コマの保持をそのままゲームへ移し、以前指摘されたがくがくした歩行へ戻す方針ではありません。足が画面外や遮蔽される場面から、足裏の圧力や正確な関節角度は推定しません。

追加の第19・21話も短区間の連続フレームで確認しました。上記の着地や突きは、動作ごとに全身の構えを変える方針を補います。正確な重心や荷重、足裏で受ける順序は映像だけでは断定しません。第21話の確認範囲でも通常歩行の安定した一周期全体は得られていません。
