## 現行の動きとの比較と次の調整方針

2026年10月3日の全身表現の更新（cba31d9）では、歩行の胸と骨盤の逆回旋、肩と肘からの腕振り、視線の安定、ソードの骨盤先行と反対腕の引き戻しを追加しています。参考映像の確認前に実装した更新であり、これを映像との一致を検証した再現版とは扱いません。

映像では、武器の角度だけでなく、動作の目的に合わせて脚・胸・左右の腕を構え直すことが明瞭です。現行のソードには全身の連動がありますが、映像の飛び込むような接近や、低い受け止め姿勢に比べ、前傾と姿勢の高低差が小さく見えます。

次の攻撃調整は「低くためる→鋭く踏み込む／振る→身体で動きを受け止める→次の構え」の姿勢差と時間配分を優先します。腕だけへ振りを追加するのではなく、支持脚、骨盤、胸、肩、反対腕を一つの全身姿勢として調整します。映像には跳躍・空中斬撃もありますが、それを全通常攻撃へ加えることは今回の確定仕様ではありません。

第2話13:25.37〜13:26.34の一動作では、振り上げから接触までと、その後の戻しに速度差が見えます。ただし現行ソード初段の打点区間も標準速度で約0.081秒あり、この一例だけを根拠に攻撃全体を速くする必要はありません。優先する差は、踏み込みで前へ運ぶ胸と肩、低い脚の構え、段ごとの全身姿勢です。

普通の歩行について、安定した一周期全体を測れる場面はこの確認範囲では得られていません。アニメの戦闘時の跳躍や飛び込みを普通の歩行へ直接置き換えず、ユーザー指定で戻した歩幅と現在の速度を基準にします。支持足の世界位置・向き、剣の握り・切断面・命中時刻、コンボと資源の戦闘ルールを検証の基準に残します。

元映像には同じ姿勢を複数コマ保持する箇所もあります。参考にするのは強い姿勢の差、準備・加速・余韻の配分です。同一コマの保持をそのままゲームへ移し、以前指摘されたがくがくした歩行へ戻す方針ではありません。足が画面外や遮蔽される場面から、足裏の圧力や正確な関節角度は推定しません。
