# 試作版 v0.1.0 の実装範囲

確定仕様の正本は SPECIFICATION.md です。このファイルは実装済みの範囲と、未確定の数値を試作のために補った部分を区別します。

## 実装した一連の操作

機体カスタム → 対戦条件設定 → 3D対戦 → 戦闘結果と報酬 → 所持品から再カスタム。味方・敵はそれぞれ1〜3機。基本品は無制限、ドロップ品は所持数を出撃時に検証。敵装備は編集できます。編集途中でコアが不足している構成は保存できますが出撃はできません。

メインはLの46マス。MGサブは頭10、胴左右5ずつ、腕左右9ずつ、脚10、合計48マス。以前の「胴12」は参照画像と一致しなかったため仕様書も10へ訂正しました。

14件のコアテストで、マス数、ランダム形状の接続と面積、必須パーツの配置、武器重量とジャンプ、狙撃クリティカル100%、汎用軽減、14/18/22個の報酬と入手アップ3機88個、有限所持数、一時停止、武器共有の弾数、空中切り替え、壁の遮蔽、全9人数構成を検証しています。

画面のDOM操作も検証し、6画面、4カスタムタブ、94セル、自動配置・戻す・やり直し、構成保存、3対3開始、ポーズ、HUD、勝利時88個の入手、バックアップと再読み込みが通りました。ローカル環境ではChromiumの起動が制限されているため、WebGLと実画面の確認はGitHub Actionsのブラウザテストで行います。テストはスクリーンショットも保存します。

## 暫定値・制約

- CPU面積4、メモリ面積6は確定。CPUの攻撃補正は汎用6%、近接10%、射撃8%、武器特化12%を試作値として使用しています。これらの補正値はユーザーの確定値として扱いません。
- メモリ枠は通常3・超1、または通常1・超3を試作値として使用しています。
- 76技の名称・武器・分類・C消費・バフ持続を設定しています。攻撃系の動作は武器と技分類による共通の手続きで表現し、個々の原作モーションは再現していません。基礎威力係数は通常3、技術5、超10を調整用に使用しています。
- FBは近接技の対象が残LP20%以下の場合の判定を試作しています。原作風の入力ミニゲームは未実装です。
- 必殺技の状態付与率の一部は暫定15%／10%です。スキル「状態異常アタック」は付与率上昇として適用します。
- CPUの遮蔽物回避は局所的な移動・ジャンプです。ステージ全体の経路探索や学習は行いません。
- モデル・武器・エフェクトはThree.jsの図形で生成します。個別の高精細モデル、音楽、効果音、演出映像は未実装です。
- ローカル対戦とCPU戦の試作です。ネットワーク対戦、アカウント、クラウド保存はありません。
- スマートフォンのタッチ操作を提供していますが、性能・操作感の調整は引き続き必要です。

ブラウザの保存領域が使えない場合はエラーを表示します。バックアップはJSONで書き出し、読み込み時に形式を検証して現在の保存を置き換えます。

## 提供動画を参考にした全身動作の調整（2026-10-02）

参照資料はユーザー提供の videoplayback(1).mp4（約130秒、W超カスタムの紹介映像）と videoplayback(2).mp4（約90秒、武器別の紹介映像）。前者の16〜23秒付近、後者の20〜23秒・26〜32秒・36〜40秒付近を主に参考にしました。斬り方向の切り替え、踏み込み、連打時の姿勢変化、ハンマーの振りかぶり、被弾側の動作が見えます。カスタム画面と機体イラストも輪郭の参考にしています。短い編集映像なので、正確な入力受付時間、全コンボ段数、派生条件を測定できたとは扱いません。モデルは独自の図形で生成し、原作画像・モデルを素材として組み込みません。

- 毎段一律に待機姿勢へ戻る動作を変更しました。先行入力があると、回復区間から次段の準備姿勢に向かい、次段の開始時は直前の腕・胴体・足の姿勢を引き継ぎます。単発で止める場合は構えへ戻ります。
- 武器別の振りかぶり・命中・振り抜き・回復を設定しました。軽い武器は早く振り、ハンマーやサイスは準備を長く取ります。近接の表示と命中区間を同じデータで管理し、斬り返しでは判定の走査方向も反転します。近接動作は既存の攻撃間隔全体を使うため、従来の短い動作より振り抜き・回復中の行動制約が長くなる武器があります。基礎威力、通常コンボ段数、攻撃間隔、テンション消費のデータは変更していません。
- 通常近接には0.15〜0.36の小さな前進を追加しました（調整用の仮値）。壁は通常移動と同じ判定で止まり、相手の手前でも前進を制限します。チャージ突撃など既存のダッシュ動作と前進を同時に加算しません。

- 被弾方向に応じた短い胴体ののけぞりを追加しました。ガード中は小さく、重い武器は大きく反応します。これは表示用で、既存の状態異常・怯み・転倒判定とは別です。射撃の反動は腕だけでなく胴体にも連動します。
- 胸から腰へ絞る形状、顔面と頬の装甲、肩の外形、前腕・すねの先細り、腰の装甲、足の甲を作り直しました。ナイトの頭の飾り、ストライダーの細いフィン、ワイルドの耳・背面、ブロウラーの幅広い肩、パンツァーの重い胸・履帯で輪郭を分けます。部位を混在させるカスタムも維持します。

## 人の動きを参考にしたモーション・攻撃中断の改善（2026-10-02）

参照資料は [England Boxing のコーチングハンドブック](https://www.englandboxing.org/wp-content/uploads/2022/03/EB_Boxing-Coaching-Handbook-Part-1_v8-002.pdf) のストレート・フック（PDFの75・77ページ）と、[FIE掲載のランジ動作資料](https://static.fie.org/uploads/24/124021-LUNGE%20PERFORMANCE%20AND%20ITS%20DETERMINANTS.pdf) の手・胴・脚の順序（PDFの2ページ）。腰の回転、安定した構え、反対の手のガード、突きの腕の先行を、ロボットの短い手足に合わせた独自の手続き型モーションへ反映しました。人のモーションキャプチャや原作動作の完全再現ではありません。

- ナックルは左足前の構えを維持し、左右パンチごとの足の入れ替えを廃止。拳は顎に近い高さに上げ、反対の手は構えに残し、後ろ足のかかと・骨盤・肩・腕を連動させます。アッパーでは軽く沈んで拳を上げ、飛び跳ねません。肘は下へ曲がる向きを基準にしました。
- 斬撃の手の軌跡を曲線にし、手首の回転は最短方向へ補間。振り下ろし・振り上げ・振り抜きの姿勢を作り直しました。骨盤から肩、腕の順に動き、胴体のひねりを抑えます。突きは胴を直立させ、腕の伸ばしが踏み込みに先行します。ハンマーは準備27%、振る区間27〜48%、振り抜き48〜70%、回復70〜100%に調整しました。
- 軽い命中で遅い攻撃が取り消される際、攻撃間隔全体の再使用待ちが残っていた問題を修正。中断された近接の残り待ち時間を最大0.14秒へ短縮します。怯み・転倒・状態異常が終わるまでは攻撃できず、テンションは返しません。段数と先行入力・チャージもリセットします。射撃の残弾・再使用待ちは短縮しません。
- 通常近接に有限の「踏ん張り」を追加。容量の仮値はランス34、ナギナタ38、サイス42、ハンマー52。開始0.04秒後から命中区間終了まで有効で、疲労攻撃・チャージ待機・出始め・戻しでは無効。被弾ダメージは通常通りです。近接の衝撃は `(8 + min(0.9, 基礎間隔) × 32) × 威力係数 × 判定の分配係数 × (1 + チャージ量)`、射撃は先頭の括弧部分を12にし、各判定の衝撃の下限を1とします。容量を使い切った命中で怯み、中断します。終段・必殺技・バズーカは踏ん張りを無視し、状態異常の抽選も妨げません。連射弾は通常の小反応を維持し、踏ん張りを使い切った場合に限り中断できます。既存のハンマー強化中の耐怯みは維持しています。
- 有効中はHUDへ踏ん張りの残量を表示。ポーズで有効時間も停止します。これらは遅い武器にも攻撃を通す機会を作る調整値で、全組み合わせの勝率を均等にしたとは扱いません。

検証は44項目。遅い4武器と速い4武器について、双方の先手、処理順、60/120fpsを変えた192条件の近距離連続攻撃で、両者がダメージを与えられることを確認します。有限の踏ん張り、ダメージ非軽減、終段・技・爆発・状態異常での突破、中断からの復帰、射撃待ち時間の保持、パンチ時の足と構え、手首の回転連続性も検証します。ブラウザでは19武器・5フレームの表示、ソード・ナックル・ハンマーの連続動作、踏ん張りHUDとハンマー対ナックルの実時間対戦を確認し、画像・動画を保存します。

## 通常攻撃モーションの追加調整（2026-10-02）

ユーザーの「チャージ専用動作より先に通常攻撃を作り込む」という方針に合わせ、通常コンボを優先して調整しました。既存の人の動作資料と提供動画を参考にした独自の手続き型モーションを継続します。

- ソードの初段は肩付近から対角へ振り抜き、二段目は低い構えから高い位置へ斬り返します。レイピアの重複した突きは、内側へ通す突きに変更しました。高い突き・低い突き・終段の伸ばす突きと手の位置、引き戻しを分けています。
- 二刀流は右斬り、左斬り返し、両手振り上げ、右斜め斬り、左斜め斬り、両手の終段に作り分けました。片腕で斬る段では反対の剣を構えに残し、両腕を使う段だけ少し時間をずらして振ります。左右の独立命中を追加したわけではなく、既存の1段としての判定を使用します。
- ナックルの三・四段目は低い位置への右・左パンチにし、上段パンチと高さ、胴体の傾き、重心を分けました。反対の手の高いガード、左足前の構え、フック、アッパーを維持しています。
- ハンマーは腰を回す横振りと頭上からの振り下ろし、ナギナタは高低差のある往復の薙ぎと終段の斜め斬り、サイスは薙ぎと刃を引き込む終段に変更。両手武器を同じ軌跡で振る部分を減らしました。ランス終段は腕をより伸ばして腰を沈めます。両手武器の支持手の向きも柄に追従します。
- 振る区間の手の補間を、徐々に加速し、振り抜きに向かって減速する形に変更。待機・先行入力した次段へのつながりを維持します。二刀流・ナックルの軌跡表示は攻撃する側に限定し、構えている側の手に攻撃の軌跡が付くのを抑えます。
- 射撃は最初の短い反動と長めの戻しを作り、片手銃・連射銃・狙撃・散弾・ランチャーで反動量と銃口の持ち上がりを分けました。二丁拳銃は左右の反動を少しずらします。これは表示上の調整で、同時発射の判定を変更するものではありません。

通常コンボの段数、攻撃間隔、威力、テンション消費、命中区間、踏ん張りの設定を維持しています。チャージ専用モーションの本格的な作り込みは今回の対象に加えず、既存のチャージ動作を通常斬撃へ置き換えないことを検証します。

検証は47項目。各武器の全通常コンボ段の姿勢が異なること、左右斬撃の構えと軌跡、上段・下段パンチの高さ、両手の接続と支持手の向き、射撃反動の差と終了後の復帰を追加確認しました。以前の関節・足の接地・コンボ接続・192条件の遅い武器対速い武器の対戦チェックも維持します。ブラウザでは全19武器・5フレームの画像、通常近接9種類を3組に分けた連続動作動画、片手銃・二丁拳銃・狙撃の射撃動作動画と、実際のソード4段・ハンマー対ナックルの対戦を確認します。原作の完全な再現、方向派生・専用空中動作・76技の個別演出は継続して改善対象です。

## ソード通常コンボの関節アニメーションへの変更（2026-10-02）

ユーザーが現在の動きの品質に不満を示したため、ソードの通常攻撃4段に対象を絞って作り直します。提供動画の振りかぶり・踏み込み・切り返しを参考にした独自の動作で、原作のアニメーションデータやモーションキャプチャは使用しません。新しい調整データは `src/sword-motion.js` にあります。

- ソードは手首位置から肘を自動生成する方式をやめ、肩の回転、肘の曲げ、前腕のひねり、手首の握り方向をキーごとに指定する順運動学へ変更しました。腕の骨格から手と剣の位置が決まります。ソードの待機姿勢にも同じ関節を使用します。肩装甲は上腕に追従し、腰の装甲は胸ではなく骨盤に取り付けます。
- 斜め斬り、斬り返し、低い位置からの斬り上げ、頭上からの振り下ろしを全身の姿勢として作成しました。胸、骨盤、肩、盾側の腕、沈み込み、重心移動を合わせて指定します。振り下ろしでは剣先自体が前方から下へ抜け、剣を垂直に保ったまま手だけを下げる動作にしません。刃の面で叩く向きにならないよう、振る方向へ刃先を向ける握りも指定します。
- 中間キーごとに停止する補間を避け、数値とクォータニオンに連続した接線を持つ三次補間を使います。先行入力があると次段の準備姿勢へつなぎ、肩・肘・前腕・手首・胸・骨盤の全チャンネルを次段へ引き継ぎます。単発停止時の戻しには、刃を胴体から離して構えへ戻す経由姿勢を加えています。

## 歩幅を広げて通常移動を高速化（2026年10月3日）
