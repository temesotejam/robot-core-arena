# 試作版 v0.1.0 の実装範囲

確定仕様の正本は SPECIFICATION.md です。このファイルは実装済みの範囲と、未確定の数値を試作のために補った部分を区別します。

## 実装した一連の操作

機体カスタム → 対戦条件設定 → 3D対戦 → 戦闘結果と報酬 → 所持品から再カスタム。味方・敵はそれぞれ1〜3機。基本品は無制限、ドロップ品は所持数を出撃時に検証。敵装備は編集できます。編集途中でコアが不足している構成は保存できますが出撃はできません。

メインはLの46マス。MGサブは頭10、胴左右5ずつ、腕左右9ずつ、脚10、合計48マス。以前の「胴12」は参照画像と一致しなかったため仕様書も10へ訂正しました。

14件のコアテストで、マス数、ランダム形状の接続と面積、必須パーツの配置、武器重量とジャンプ、狙撃クリティカル100%、汎用軽減、14/18/22個の報酬と入手アップ3機88個、有限所持数、一時停止、武器共有の弾数、空中切り替え、壁の遮蔽、全9人数構成を検証しています。

画面のDOM操作も検証し、6画面、4カスタムタブ、94セル、自動配置・戻す・やり直し、構成保存、3対3開始、ポーズ、HUD、勝利時88個の入手、バックアップと再読み込みが通りました。ローカル環境ではChromiumの起動が制限されているため、WebGLと実画面の確認はGitHub Actionsのブラウザテストで行います。テストはスクリーンショットも保存します。

## 暫定値・制約

- CPU面積4、メモリ面積6は確定。CPUの攻撃補正は汎用6%、近接10%、射撃8%、武器特化12%を試作値として使用しています。これらの補正値はユーザーの確定値として扱いません。
- メモリ枠は通常3・超1、または通常1・超3を試作値として使用しています。
- 76技の名称・武器・分類・C消費・バフ持続を設定しています。攻撃系の動作は武器と技分類による共通の手続きで表現し、個々の原作モーションは再現していません。基礎威力係数は通常3、技術5、超10を調整用に使用しています。
- FBは近接技の対象が残LP20%以下の場合の判定を試作しています。原作風の入力ミニゲームは未実装です。
- 必殺技の状態付与率の一部は暫定15%／10%です。スキル「状態異常アタック」は付与率上昇として適用します。
- CPUの遮蔽物回避は局所的な移動・ジャンプです。ステージ全体の経路探索や学習は行いません。
- モデル・武器・エフェクトはThree.jsの図形で生成します。個別の高精細モデル、音楽、効果音、演出映像は未実装です。
- ローカル対戦とCPU戦の試作です。ネットワーク対戦、アカウント、クラウド保存はありません。
- スマートフォンのタッチ操作を提供していますが、性能・操作感の調整は引き続き必要です。

ブラウザの保存領域が使えない場合はエラーを表示します。バックアップはJSONで書き出し、読み込み時に形式を検証して現在の保存を置き換えます。

## 武器の取り付け表示の修正（2026-10-02）

武器モデルの原点を握りの中央にそろえ、左右の手に直接取り付けます。肩・肘・手の位置を分け、待機画面と戦闘で同じ構えを使います。剣の刃は腕から離し、銃口は正面へ、狙撃銃の銃身も銃口方向へ向けます。二刀流・二丁拳銃・ナックルは左右の手に装備し、両手銃とハンマー・ナギナタ・サイスは左手が支持位置を追従します。盾は左手の前に配置します。

全19武器と5フレームで、移動・攻撃・ガード・空中・転倒・撃破・武器切替時の接続を検証します。ブラウザでは全19武器の正面・側面・攻撃中のスクリーンショットを保存して見た目を確認します。武器性能や保存データの形式には変更を加えません。
