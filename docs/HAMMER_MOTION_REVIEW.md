# 大型ハンマー：横の下段構えと全身の斜め振り

確認日：2026年10月4日。通常構えと攻撃が不自然という指摘を受け、「大剣のようなモーション」「ハンマー自体を大きく、味気ない外観を改善する」という指定に合わせる。承認されたポーズ案に合わせ、肩を少し前へ出し、両手を腰の横へ下げ、ヘッドを右腿の外・後方の低い位置へ引く。ここから骨盤・胸・両腕で斜めに振り込む。承認済みのLBX体型、ソード・ナックル・ランスを基準にする。

## 武器の外観

長い補強柄に、機体の肩幅に近い大型ヘッドを付ける。中央は面取り装甲、左右は厚い独立した打撃面。打撃面の補強板・溝・留め具、側面の暗いパネルと斜線、発光レール、柄の補強カラーで立体的な構造を示す。敵側も同じ構造でチーム色を使う。装備の交換・破棄には既存の共有形状／材質キャッシュを使う。

右手を元の握り位置から0.14ヘッド側へ進め、左手を柄の端側に置く。支持間隔は0.14にする。一本の武器全体を新しい右手の原点へ移し、モデルの大きさ、柄の長さ、骨長を保つ。左拳の両端が柄の実形状を囲む位置を使う。新しい原点ではヘッド中心と軌跡先端はローカルY=0.46で一致し、元の大型ヘッドそのものの通過で検証する。ヘッドは柄の中央軸へ直角に接続した既存の剛体形状を保持し、ヘッドだけを独立して傾けない。

## 構えと攻撃

- **通常構え：** 肩を約0.15rad前へ傾け、両手は腰の横の少し前、ヘッドは右腿の外から後方へ引いた下段に置く。柄はほぼ水平から少し下がる向き。左足を前へ開いて腰を落とし、顔は相手へ向ける。Knightの実描画では右手の握りの高さ約0.44、ヘッド中心約0.35、ヘッドは左手より後方約0.50。大型外形の下端も床上を保ち、幅の広い履帯の外側へも逃がす。
- **1段目 `hammerSweep`：** 下段の後方から右側の外を通して持ち上げ、骨盤が先に開き、胸と両腕が続く。高い右側から正面の相手を通過して低い左側へ振り抜く。単発なら正面の外側から右側を回収し、下段の後方へゆっくり戻す。
- **2段目 `hammerSlam`：** 1段目の左側の終端から左上へ集め、反対向きに斜めに振り下ろして右側へ抜く。通常2段とも同じ中央の叩きつけを繰り返さない。既存クリップ名は互換性のため保持する。
- **溜め：** 下段から右側の外を通して深く高く引き、大きい踏み込みと上体の折り込みで一度振り下ろす。解除後は準備した姿勢から動き、待機へ戻して振りかぶり直さない。終了後は外側を通して同じ下段の構えへ戻す。

顔は相手を向き、両手は一本の剛体の柄を持つ。手元・柄の方向・胸・骨盤・握りのロールを連続曲線で動かす。柄の方向ベクトルから一つの回転を作り、ロールも手と武器全体へ適用する。ヘッドだけが別の回転をすることはない。握り全体を両腕の到達域と手首の角度の許容範囲へ収め、支持手だけを柄から離したり、骨を伸ばしたりしない。基本姿勢と同じ関節から開始する場合は、設計済みの外側の経路へさらに初期姿勢をブレンドして胴を横切らせない。段間・溜め解除で保存された別姿勢は既存の引き継ぎ経路を使う。

## 腕の食い込みの修正

低い握りと後ろ向きの肘平面が、特に支持側の前腕を胸へ通していた。さらに待機時の旧支持手IKが新しい肘の姿勢を上書きしていた。握りの回収経路を少し前へ出し、肘平面を前・外へ向ける。肩ソケットを前へ、わずかに外へ運び、両腕の共通到達域には伸ばし切らない余裕を残す。両手が胸の前側にある条件と両腕の到達条件を、一本の握り全体へ適用する。骨長0.195×2は保持する。

両手を近い同じ向きの握りへ集めると、後ろ向きの柄では左手が右手の後ろへ回り込み、前腕の装甲同士が重なって見える。ハンマーは右手より柄の端側へ左手を置き、両手の間隔を0.09から0.14へ広げる。両手の握り軸は同じ一本の柄に沿わせ、各拳の長軸はその前腕に近い向きへ置く。柄の支持点はモデル・IK・段間・溜め解除で共通設定を使う。手の順だけを逆にしてヘッドまでの距離を延ばさず、元の柄の軌道と対応するヘッド側の原点を一緒に使う。他の両手武器の支持位置は既存値を保つ。回収中は先に腰の高さへ手元を戻してから柄を後ろへ引き、胸の前の余裕も確保する。

ハンマーの肩装甲は前方への挙上に沿って傾け、肘平面のねじりによって内側の端を胸へ倒さない。胸と腕の装甲幅に応じた逃げを入れ、幅の広い胴や左右別の装甲にも対応する。通常の他武器は既存の肩追従を使う。待機・歩行はこの両手持ちを維持し、左右独立の腕振りと旧支持手IKで上書きしない。段間と溜め解除でも肩移動を補間する。1段目の回収をゆっくり通し、大型ヘッドを振り抜く高さも確保する。

大型ヘッドの下端が床を越えないよう、振り抜きの角度と手元の高さを設計する。前足は位相0.29で着地し、通常は後足を0.65までに寄せ、前足の回収を0.94までに終える。溜めは後足の回収0.45、最後の回収0.72。Wildtailの深い沈みは既存の床上補正を使う。モデルの体型・骨長や他武器の動作は変えない。


## 手首と構えの方向の修正

以前は左右の拳を柄の回転へ固定し、前腕との差をすべて手首へ与えていた。前腕のロールは常に0で、支持側にはさらに柄まわりの180度回転を与えていた。拳が支持点に一致していても、手首が前腕に対して逆向きになるケースをこの検査では捉えられなかった。

ハンマーでは柄の剛体フレームと拳の向きを分ける。各拳の握り軸は柄と一致し、拳の長軸は前腕を柄に直交する面へ投影した方向にする。必要な軸回転は前腕へ配分し、手首には中立の握りからの屈曲だけを残す。腕のFKと描画する手は同一で、武器は手からの相対回転で剛体フレームを維持する。各拳の柄まわりの向きは、その前腕から決める。

通常構えの柄はpitch=1.77、azimuth=-2.80へ戻す。前の持ち方修正でazimuthを-2.60へ変えた分を戻す。両手を少し右の外側へ逃がし、前腕との接続を整え、通常構えの手首の屈曲を18度以内にする。攻撃・保持・入力からの継承では35度以内を検査する。武器全体の向きは必要に応じて両前腕に合わせ、手首へ無制限の回転を押し込まない。

了承された元画像「中央接続のT字型メカニカルハンマー.png」と再照合し、ヘッドの長軸が横向きであることを確認した。前回の剛体ロール=π/2は、横棒を縦に立てる取り違えだった。ロールをπ-2.80（約0.342rad）にし、ヘッドの長軸を水平面内で柄に直交させる。T字接続、柄の方向、モデル寸法、両手と前腕の姿勢は保つ。肩や背中のフィンを通す時間は待機時のロールから分離し、回収でヘッドが低く戻ってから横向きへ戻す。

ハンマーを持つ手は中央を貫通した一個の黒い箱から、柄の周囲を囲う掌・4本の閉じた指・親指へ替える。左右の親指は各手の人差し指側へ置く。握りの軸、骨長、両手の間隔、手首角度は変えず、指が柄を包む構造を描画する。装備を替えると他武器の既存の手へ戻す。

共通の打撃部の床判定も変換後の実頂点を使う。面取りしたヘッドに存在しない外接箱の角は、床への貫通として扱わない。床上のしきい値0と専用の全外形・実入力検査は保持する。

振りかぶりは肘を上げる連続した平面を使い、回収は手元の高さを保ちながら上の外側から戻す。背中のフィンの近くは武器全体を柄まわりに回し、大型ヘッドを細い向きで通す。ヘッドだけを独立して回さず、了承された通常構えへ戻す。1段目の回収はヘッドの経路長から時間配分を作り、急な最後の下ろしを抑える。接触位相と戦闘値は変えない。
